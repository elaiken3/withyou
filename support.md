# Support — WithYou

Thanks for using WithYou.

## Get help
Visit the support page: https://wearewithyou.app/support/

## Report a bug or suggest an idea
Please use GitHub Issues in this repository:
https://github.com/elaiken3/withyou/issues

There are templates for bug reports, feature requests and UX feedback.

## What to include in a report
- Device model + iOS version
- App version (shown in TestFlight or the App Store)
- What you expected to happen
- What actually happened
- Steps to reproduce (if possible)
- Screenshots or screen recording (if available)

Please don't include personal content (your captured thoughts or tasks) in public issues.

## Notifications and the daily check-in
Reminders, focus endings and the optional daily check-in are all created on your iPhone. If they don't show up, check iOS Settings → Notifications → WithYou. The daily check-in is off until you turn it on in WithYou's Settings (the gear on Today).

## Cloud AI
Cloud AI is off by default. You can turn it on or off in WithYou's Settings, under AI help. "Delete my cloud AI data" there removes the anonymous ID and daily usage counts WithYou's server keeps for it. See the privacy policy for what is sent.

## TestFlight Feedback
If you’re testing through TestFlight, you can also use “Send Feedback” from the TestFlight app.

## Privacy
See the privacy policy: https://wearewithyou.app/privacy/
